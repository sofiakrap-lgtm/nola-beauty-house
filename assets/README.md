# assets/ — Nola Beauty House

Tähän kansioon liitetään brändin mediatiedostot. Pidä nimet selkeinä,
pienillä kirjaimilla ja väliviivoilla (esim. `nola-wordmark-espresso.svg`).

## Rakenne

| Kansio      | Sisältö                          | Formaatti |
| ----------- | -------------------------------- | --------- |
| `logos/`    | Logot, wordmarkit, monogrammit   | `.svg`    |
| `graphics/` | Grafiikat, ikonit, koristeet     | `.svg`    |
| `images/`   | Valokuvat (iho/hius/interiööri)  | `.jpg`    |

## Käyttö HTML:ssä

```html
<!-- Logo -->
<img src="assets/logos/nola-wordmark-espresso.svg" alt="Nola Beauty House" />

<!-- Kuva -->
<img src="assets/images/hero-interior.jpg" alt="Modern vintage -interiööri" />
```

## Nimeämisvinkit

- Logot: `nola-[tyyppi]-[väri].svg` → `nola-monogram-ice.svg`
- Kuvat: `[osio]-[aihe].jpg` → `hero-interior.jpg`, `galleria-iho-01.jpg`
- Pidä kuvamaailma brändissä: filmirae, lämmin luonnonvalo, plaster/nahka/puu.
